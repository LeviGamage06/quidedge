# Service videos go here

Drop your 4 service videos into this folder using **these exact names** (including
the spaces and capital letters), and they'll auto-play in the matching slots on the
Services page. Until a video is added, that slot shows its current image instead —
nothing breaks.

| Service slot | File name to use |
|---|---|
| 01 · Personal Branding | `Personal Branding.mp4` |
| 02 · Viral Engineering | `Viral Engineering.mp4` |
| 03 · Retention Editing | `Retention Editing.mp4` |
| 04 · Multi-Platform Growth | `Multi Platform Growth.mp4` |

Notes:
- Videos autoplay **muted** and **loop** (browsers require muted for autoplay).
- Keep them short and web-optimised (MP4 / H.264, ideally under ~10 MB each) so the
  page stays fast — these download when the page loads.
- After adding files here, commit + push (GitHub rebuilds) — or run `npm run dev`
  locally — for them to appear.
- This `README.md` is harmless; you can leave it or delete it.
